# 👤 Profile Card

A simple **Profile Card** built using **HTML** and **CSS**. It displays a profile image, name, role, about section, location, and a contact button.

## 🔗 Live Demo
https://github.com/Manishjoshi03/resume/projects/profile%20card
## 🚀 Technologies Used
- HTML5
- CSS3
- Flexbox

## ✨ Features
- Clean profile card design
- Circular profile image
- Flexbox layout
- Styled contact button
